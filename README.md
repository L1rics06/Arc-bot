# ARC-BOT

## 这是什么
这是一个由rust `kovi` 机器人框架的一个仓库，该项目本人不会使用现代agent工具辅助，
并将ai的使用尽量停留在查找资料的程度上，
也就是说，该项目可能是一个长期的项目，并且更新频率可能会很低。

## 为什么古法编程
本人是只是一个大三本科生，在一段时间因为ai处于一种非常焦虑的状态，当然，本人也完全依靠ai做过开源工程，
但是现在，我想慢下来，让写代码只是成为一种爱好，回归编程原始的乐趣。

## 屎山代码警告⚠️
前面说了这么多，该项最后也是只是一个练习项目，加之本人羸弱的编程水平，可能会出现很多屎山代码 Orz
